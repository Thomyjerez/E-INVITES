# 🌿 Botanical Union - Digital Wedding Invitation

Una aplicación web de invitación de bodas premium, interactiva y completamente responsiva. Diseñada con una estética boho-chic/botánica (tonos salvia, arena, terracota y olivo), enfocada en ofrecer una experiencia de usuario fluida, elegante y similar a una app nativa.

##  Características Principales

* **Landing Interactiva (El Sobre):** Animación inicial inmersiva construida con CSS puro y Framer Motion. Un sobre geométrico que se abre al interactuar con un sello de lacre virtual.
* **Diseño 100% Responsivo:** Interfaz *mobile-first* fluida que se adapta elegantemente a pantallas de escritorio mediante un diseño de columnas centralizadas (`max-w-2xl`).
* **Reproductor de Ambiente Personalizado:** Reproductor de música integrado con onda de sonido animada y soporte para carga de pistas de audio locales (`.mp3`).
* **Cuenta Regresiva en Tiempo Real:** Contador animado dinámico hacia la fecha del evento (24 de Octubre de 2027) utilizando `framer-motion` para transiciones fluidas de números.
* **Itinerario Interactivo:** Línea de tiempo tipo acordeón que revela información detallada, tips y recomendaciones al hacer clic en cada evento del cronograma.
* **Carrusel de "Ambiente del Lugar":** Ruleta horizontal de imágenes con efecto *snap-scroll* y controles de navegación por flechas, optimizada para uso táctil y mouse.
* **Guía de Estilo Visual:** Sección dedicada al código de vestimenta con visualizador interactivo de la paleta de colores sugerida.
* **Formulario RSVP Dinámico:** Flujo de confirmación de asistencia con campos condicionales (acompañantes, restricciones alimentarias) y notificaciones de éxito (simuladas en frontend).

## 🛠️ Tecnologías Utilizadas

* **Frontend Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Enrutamiento:** [React Router v6](https://reactrouter.com/) (Navegación SPA sin recargas)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Animaciones:** [Framer Motion](https://www.framer.com/motion/) para transiciones de páginas, acordeones y el sobre interactivo.
* **Iconografía:** Google Material Symbols.
